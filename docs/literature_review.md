# 主实验依据

本次核查针对已定义的序列概率比对照，检索日期2026-11-15。

- DeepSeekMath v3第4.1节定义GRPO，含组内相对奖励和token级策略比。它支持优势构造的来源说明，序列AM目标需要本项目独立实现。[原论文](https://arxiv.org/html/2402.03300v3#S4.SS1)
- DeepSeek-R1报告说明基于GRPO的推理强化学习与规则奖励，不能直接提供本项目AM/GM单变量比较结论。[报告](https://arxiv.org/abs/2501.12948)
- GSPO v2第4.1–4.2节使用长度归一化序列概率比及序列裁切，为本项目GM目标提供直接公式背景。论文中与GRPO的比较同时涉及token/sequence裁切等差异，须作为间接实验依据。[原论文](https://arxiv.org/html/2507.18071v2#S4)
- Memory R2尚未唯一匹配到本项目所指的目标函数来源，保持未核实。本项目公式已由协议单独定义，不影响实现。

尚无本项目训练结果。AM≥GM的数学关系不能预测裁切和正负优势下的训练优劣。五seed完成后再计算配对统计；首seed只报告个案。
