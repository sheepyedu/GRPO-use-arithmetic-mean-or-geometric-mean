# Qwen3-8B 序列概率比 AM/GM 受控实验协议

本项目已在PAI启动首seed四个正式条件，尚无完整正式训练结果。本协议规定实施、验证与正式实验流程。当前代码、数据和后端决策见README及实施决策文档，首seed17正式完成0/4。

## 1. 目标与模型

比较序列概率比的算术平均（AM）与几何平均（GM）在两个训练环境中的表现，即纯数学环境，以及数学、基础科学与常识、阅读理解混合环境。

主模型固定为官方 `Qwen/Qwen3-8B`。实施实验时核实模型许可证、架构、聊天模板、推理后端兼容性并固定 checkpoint revision。不得静默换用其他模型、量化版本或蒸馏模型。默认统一启用 Qwen3 thinking 模式，明确记录聊天模板参数及实际行为。若所选后端不能支持该设置，先解决兼容性或统一修订协议，再启动正式实验。

训练 temperature=1.0、top-p=1.0，评估 temperature=0、每题一次贪心生成。配对 seed 为 `[17, 29, 43, 71, 101]`。正式矩阵为 2 个环境 × 2 个目标 × 5 个 seed，共 20 个运行。

| 训练环境 | AM 运行数 | GM 运行数 | 配对 seed |
|---|---:|---:|---|
| 纯数学 | 5 | 5 | 17、29、43、71、101 |
| 混合 | 5 | 5 | 17、29、43、71、101 |
| 合计 | 10 | 10 | 共 20 个运行 |

## 2. 文献与研究对象

实施阶段核查 DeepSeekMath、DeepSeek-R1、GSPO、相关 GRPO 变体及尚未唯一识别的 Memory R2，优先使用原论文、附录和作者实现，记录版本、公式位置、永久链接与代码 revision。Memory R2 无法确定时记录候选，不阻塞明确定义的主实验。

严格区分奖励基线、优势标准化、token 概率比聚合、序列目标和裁切位置。不能对可能为零或负数的奖励直接求几何平均。证据表分别标记严格受控对照、含其他改动的间接证据和理论讨论。不能将未检索到证据写成不存在相关研究。

后续产物为 `docs/literature_review.md`、`docs/evidence_table.csv` 和 `docs/method_decision.md`。文献核查及证据结论尚待完成。

## 3. 数据与划分

使用英文公开数据，两个环境各包含 6,000 个唯一训练题。

| 数据集 | 纯数学训练 | 混合训练 | 验证 | 锁定测试 |
|---|---:|---:|---|---|
| GSM8K，`openai/gsm8k`，main | 6,000 | 3,000 | 官方 train 固定留出 1,000 | 官方 test |
| ARC-Easy，`allenai/ai2_arc`，ARC-Easy | 0 | 1,500 | 官方 validation | 官方 test |
| BoolQ，`google/boolq` | 0 | 1,500 | 官方 train 固定留出 1,000 | 官方 validation |

实施时核验数据 ID、配置、schema、许可证和 revision，保存数量及内容哈希。BoolQ 官方 validation 在本项目中仅用于最终测试，不参与调参。混合环境的数学题是纯数学训练池的子集。

使用独立于训练 seed 的固定数据 seed，建议固定为 2026。先锁定测试集，再排除训练和验证中与测试重复的记录。检查跨来源规范化重复及近重复，数学题规范化时保留数字。保存排除规则、计数和划分 manifest，不依据测试表现筛选样本。

去重后训练样本不足时，优先使用同来源剩余合格训练题补齐。仍不足则在正式运行前按 50%/25%/25% 比例统一缩减两个环境的训练规模，不复制样本补足。缩减后两个环境保持相同训练题总数，混合环境保持该比例，纯数学环境仍全部使用数学题。验证集按实际合格数量报告。披露基础模型预训练污染的不确定性。

每个 rollout 批次含 64 个 prompt。混合环境固定为 32 道数学、16 道 ARC-Easy、16 道 BoolQ，使用可复现的循环洗牌和批内打乱。配对 AM/GM 运行共享数据清单和 prompt 顺序规则。

## 4. 提示、奖励与校准

统一聊天模板与 thinking 设置，允许推理，最终答案使用唯一 `Final answer:` 标记。默认最多生成 2,048 token，包括推理内容。仅依据验证集截断情况统一调整长度。

奖励为正确 1、错误或无效 0，不增加格式奖励、长度奖励或额外监督训练阶段。

- GSM8K 从官方答案提取数值标签，只解析最终答案中的受限数值表达，支持约定的逗号、小数及分数，精确比较。不执行模型输出，也不从推理过程搜索匹配数字。
- ARC-Easy 沿用原始选项标签，检查答案合法性，不假设所有题目的选项数量相同。
- BoolQ 保留原文和问题，只接受规范化的 yes/no。

训练和评估采用同一解析规则，覆盖重复标记、矛盾答案、空输出及截断。截断时没有完整合法最终答案则记错。

正式训练前仅用验证数据检查初始正确率、输出长度、截断率及每题 8 次采样的零优势组比例。某来源超过 95% 的组没有奖励差异时，先排查模板、解析和长度。仍退化时，在正式实验前使用同来源独立候选训练池统一筛选有学习空间的题目并披露分布变化。来源仍无法支持有效训练则修订协议，不将退化训练视为有效对照。

## 5. 受控 AM/GM 目标

对有效生成 token 定义策略与行为策略的 log probability 差、概率比及有效长度 \(L\)。

\[
d_t = \log \pi_\theta(y_t\mid x,y_{<t}) - \log \pi_{\mathrm{old}}(y_t\mid x,y_{<t}),
\qquad r_t = \exp(d_t), \qquad t=1,\ldots,L.
\]

AM 使用概率比的算术平均，通过 logsumexp 稳定计算。

\[
s_{\mathrm{AM}} = \frac{1}{L}\sum_{t=1}^{L} r_t,
\qquad
\log s_{\mathrm{AM}} = \operatorname{logsumexp}_{t=1}^{L}(d_t)-\log L.
\]

GM 使用概率比的几何平均。

\[
s_{\mathrm{GM}} = \exp\!\left(\frac{1}{L}\sum_{t=1}^{L}d_t\right).
\]

两组均最大化以下序列目标，按序列等权平均，并减去相同的 KL 正则项。

\[
J_s = \min\!\left(sA,\operatorname{clip}(s,1-\varepsilon,1+\varepsilon)A\right).
\]

优势由同一 prompt 的 8 个奖励计算，使用算术均值基线、总体标准差和统一数值稳定项，停止梯度。奖励完全相同时优势置零。不得跨 prompt 或跨任务求基线。以 \(R_i\) 表示组内奖励，\(\delta>0\) 为两组共享并在正式运行前固定的数值稳定项。

\[
\bar R=\frac{1}{8}\sum_{i=1}^{8}R_i,
\qquad
\sigma_R=\sqrt{\frac{1}{8}\sum_{i=1}^{8}(R_i-\bar R)^2},
\qquad
A_i=\operatorname{stopgrad}\!\left(\frac{R_i-\bar R}{\sigma_R+\delta}\right).
\]

参考 KL 使用有效 token 上的以下估计，先在每条序列内按有效 token 平均，再对序列等权平均。参考策略为冻结的初始模型。

\[
u_t=\log\pi_\theta(y_t\mid x,y_{<t})-\log\pi_{\mathrm{ref}}(y_t\mid x,y_{<t}),
\qquad
K=\frac{1}{L}\sum_{t=1}^{L}\left(\exp(-u_t)+u_t-1\right).
\]

若批次包含 \(N\) 条序列、KL 系数为 \(\beta\)，共同最大化目标为

\[
\mathcal{J}=\frac{1}{N}\sum_{i=1}^{N}\left(J_{s_i}-\beta K_i\right).
\]

两组仅改变概率比聚合算子，保持裁切位置、\(\varepsilon\)、KL、优化器、mask、EOS、截断和序列权重一致。AM 组不是标准 token 级 GRPO，报告必须明确研究对象是序列概率比聚合。

当前策略等于行为策略时，两种算子的值及一阶梯度相同。因此每批 rollout 固定进行 2 个优化 epoch，冻结行为策略 log probability，并记录 minibatch 与梯度累积配置。不得给两组不同的更新次数。

## 6. 实现、共同配置与预算

优先评估固定版本 verl，验证其对 Qwen3-8B、thinking 模板、推理后端和自定义目标的支持后固定环境。

默认 BF16 与 LoRA，rank=16、alpha=32、dropout=0。依据实际架构列明 attention 和 MLP 的目标线性模块。所有条件共享适配器初始化规则，结论限定于该训练方式。

共同初始配置如下。

| 配置项 | 初始值 |
|---|---|
| 每题回答数 | 8 |
| 每轮 prompt 数 | 64 |
| 每批优化 epoch | 2 |
| 裁切参数 \(\varepsilon\) | 0.2 |
| KL 系数 \(\beta\) | 0.01 |
| 学习率 | `1e-5` |
| 每个运行 rollout 轮数上限 | 200 |

有效 batch、微批和梯度累积在试运行后冻结。

已完成小模型端到端检查及Node01两轮纯数学Qwen3-8B的采样、反向、检查点与LoRA同步验证。2026-11-15用户要求迁至PAI直接重新训练，后续采用共同配置、必要依赖检查和正式入口，四卡同时运行四条件。具体早停和迁移决策见实施决策文档。

正式运行从原始 checkpoint 和固定初始化重新开始，不继承试运行权重。每个运行名义预算为 12,800 个 prompt、102,400 条回答，20 个运行合计 2,048,000 条训练回答。报告实际 token 和 GPU 小时，不将回答数相同称为完全等算力。

资源不足时先调整微批和梯度累积。仍需降低预算则在正式训练前统一缩减所有条件并记录，保留五个配对 seed，不依据阶段性结果修改预算。

## 7. 评价与统计

训练前、每 10 轮和训练结束进行验证。最终测试只使用预先指定的最终 checkpoint，相同模板、推理模式和长度限制，不按测试表现选择模型。

所有条件测试三个数据集。纯数学环境主指标为 GSM8K 测试正确率。混合环境主指标使用以下固定权重，其中各项均为对应测试集的正确率。

\[
M_{\mathrm{mixed}}=0.5\,\mathrm{Acc}_{\mathrm{GSM8K}}
+0.25\,\mathrm{Acc}_{\mathrm{ARC\text{-}Easy}}
+0.25\,\mathrm{Acc}_{\mathrm{BoolQ}}.
\]

同时报告逐任务正确率和等权宏平均。不按各测试集题目数量汇总混合主指标。纯数学模型在其他任务上的表现作为迁移诊断，不直接称为难度受控的分布外实验。

每个环境报告五个 seed 的 \(\mathrm{GM}-\mathrm{AM}\) 配对差值、均值和 95% 配对 t 区间，展示全部逐 seed 结果。若对两个主比较进行显著性检验，使用 Holm 校正。题目层 bootstrap 仅作补充。正式训练前预注册实际意义阈值为绝对正确率差 2 个百分点。

次指标包括固定预算下的验证学习曲线面积、生成 token、GPU 小时及失败率。跨环境的差值变化属于探索性分析，不能将数学训练量与任务组成变化的影响单独归因于混合数据。

记录奖励、组内标准差、零优势组比例、逐任务长度、截断率、熵、参考 KL、裁切比例、梯度范数、概率比分位数及 \(\log s_{\mathrm{AM}}-\log s_{\mathrm{GM}}\)。统一预注册基础设施故障重跑规则，完整披露失败和不稳定运行。

## 8. 机制诊断与后续验证

在冻结的 rollout、行为概率和优势上分别计算两个目标，比较目标值、梯度方向、范数和 token 贡献。先使用覆盖极端概率比、变长序列和不同方差的合成数据，再从四个条件的预定检查点按任务等量抽取真实 rollout。

\(\mathrm{AM}\geq\mathrm{GM}\) 不意味着 GM 性能更好，优势符号和裁切分支会改变更新。静态诊断不能替代在线训练。标准 GRPO、奖励噪声和额外分布外任务如需增加，应作为独立预算的扩展实验。

当前实现采用 `src/data.py`、`src/rewards.py`、`src/objectives.py`、`src/train.py` 及 `configs/`、`scripts/`、`tests/`、`docs/`。结果摘要保存于 `reports/`，原始大产物在服务器 `artifacts/`。维护 `README.md`、`TEST.md` 及同步的项目指南。

关键验证包括以下内容。

- \(\mathrm{AM}\geq\mathrm{GM}\)，全一概率比处值与一阶梯度一致，正负优势裁切及极端 log ratio。
- padding/EOS、变长和截断处理，零方差奖励，行为概率冻结与多 epoch 更新。
- 三类答案解析、非法输出拒绝、数据隔离、混合比例和配对顺序可复现。
- 自动检查同一环境下 AM/GM 配置仅在算子及运行标识上不同。

单元、合成集成及小模型端到端检查已完成，Node01已有两轮指定模型试运行证据；按用户最新要求在PAI完成必要环境检查后，从正式入口重新训练。保存配置、模型与数据 revision、数据哈希、代码版本、seed、软硬件清单、原始日志、失败记录及 checkpoint。

最终研究交付包括文献证据、冻结协议、可复现实现、20 个运行的可追溯结果、逐环境配对统计及机制分析。证据不足应明确说明，不将无显著差异视为等价。只完成实现或试运行时明确标记正式训练未完成。
